# Stackpulse v0.1.0-alpha.1

The first private alpha of Stackpulse, a native falling-block game with three modes, practice tools, replays and multiplayer rooms.

## Included

- **Classic** — one preview and immediate locking, without hold or hard drop.
- **Fusion** — Classic-style progression with five previews, hold, kicks and spins.
- **Modern** — hold, ghost piece, hard drop and delayed locking.
- **Practice Lab** with repeatable seeds, frame stepping and clear/spin fixtures.
- **Replay history** for up to 100 timestamped recordings, with progress display and forward/backward seeking.
- **Keyboard and controller support**, configurable bindings and original synthesized sound effects.
- **Multiplayer rooms** for 2–8 players, with spectators, optional passwords, level selection and rematches.

## Downloads

| Package | Contents |
| --- | --- |
| `stackpulse-windows-x64.zip` | Windows x64 game, dedicated server and command-line tools, including required Visual C++ runtime DLLs. |
| `stackpulse-linux-x64-server.tar.gz` | Linux x64 dedicated server and command-line tools; no graphical client. |

Extract the complete package. On Windows, launch `stackpulse_client.exe`. For multiplayer, start `stackpulse_server.exe` and connect clients through the Multiplayer menu. The default server address is `127.0.0.1:27877`; LAN hosting supports an explicit bind address.

The Linux server requires compatible system C/C++ runtimes; see the package's runtime-dependency information. No ROM or additional game assets are required.

## Alpha notes

This is an early private build. Gameplay and file formats may change, and Classic's independently authored rules are not a reference-verified NES reproduction. Multiplayer clients and servers should use matching builds. Public matchmaking and NAT traversal are not included.

Windows/Linux tests, deterministic replay checks and native multiplayer checks passed. Package startup checks were performed on the existing development hosts, rather than clean-machine VMs. See the repository's release checks for the full validation scope.
